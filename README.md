# SOYOAI (Web版)

端末の中で動くAIチャット。最初にAIのデータをダウンロードすると、2回目からはオフラインでも使えます。

- 版: 0.3.1(Play版と同じ中身)
- 無料・広告なし・会員登録なし。会話はこの端末の中だけで処理し、保存しません。
- 🔎で調べるときだけ、検索の言葉がウィキペディアに送られます。「この答えを報告」で送ったときだけ、報告が運営に届きます。
- AI: Qwen3.5(Apache-2.0)・WebLLM(Apache-2.0)。ライセンスは THIRD-PARTY-NOTICES.txt。
- このフォルダは本体(非公開)から `node _sync_web.js` で作り直しています。ここを直接直さないでください。
- 提供: 介護と支援の相談どころ「そよぎ」 https://soudansoyogi.com/
